# Project Guidelines & Interaction Rules

---

## 1. Questions vs. Coding Execution
* **When the user asks a question, seeks clarification, asks for advice, or says "dont code":**
  * **ANSWER THE QUESTION THOROUGHLY IN PROSE / MARKDOWN.**
  * **DO NOT WRITE OR GENERATE CODE FILES.**
  * **DO NOT EXECUTE IMPLEMENTATION ACTIONS.**
* **Only write code, edit files, or execute implementation commands when the user EXPLICITLY requests or instructs to code/implement.**

---

## 2. Transparent File Modifications via Tools
* **Always use dedicated tools (`replace_file_content`, `write_to_file`) to modify, create, or delete files directly in the codebase.**
* **Never just dump code snippets in chat when instructed to make changes—apply them directly via tools.**
* **Always provide clear file links and summaries of what files were edited or added so the user knows exactly what changes occurred.**
